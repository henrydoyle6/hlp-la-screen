固定选择 Tn 前最近完整快照 `03:00:00.0364426Z`，按文件顺序应用 8,143 条 SET/DELETE 更新，截止 `time_exchange <= Tn`。SET 使用新的绝对剩余量；零剩余量只保留在内部状态，后续删除。快照按完整连续批次读取，不逐行清空。

最后已应用更新为 `03:47:55.884768Z`，比 Tn 早 122.232 ms。因此本文件保留 `book_state_point=tn_time_approximate_l4`，`last_applied_block` 和区块回放范围均为空；`target_block` 只是来自 CSV1 的参考高度。没有借助订单 ID 或近似时间擅自补写区块标签。

本试验的 `snapshot_time` 是派生盘口最后已应用更新的交易所时间，`snapshot_lag_ms=-122.232` 表示该时间减 Tn；它不是网络延迟，也不是原始完整快照年龄。真正的回放起点在 `diff_sources_json.seed_time`，其与 Tn 的差为 `-2875970.5574 ms`。输出还在该 JSON 中记录截止时间、读取行范围及对象校验和。
