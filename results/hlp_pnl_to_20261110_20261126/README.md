## 验证与来源

真实数据核验：29,954 笔原生 HLP 成交按区块、事件顺序重放，9 个真实仓位周期从零开始并归零；29,946 条 FIFO 配对以独立 Fraction 逐条复算，并与独立买卖现金流相符。原生官方 PnL 原值保存在本地来源回执中，官方 PnL 与 FIFO 的口径差异仍在 CSV 核对状态列说明，没有强行调平。

262 个被清算账户的 Account Value 通过官方清算账本的账户、交易哈希、毫秒时间、币种、方向和数量约束唯一匹配。为恢复成本链，对本地新增 240 小时及此前 168 小时作账户定向扫描；另对必要的 32 个历史小时逐区块核验，共 1,612,090 条区块记录，无内部或相邻小时缺口，并与 11 月 1 日首块衔接。

22,315 次相加、452 次聚合、全部 U、历史保留字段和五笔缺价标注通过独立精确分数核验。表格引擎对全部新增或修改单元格完成精确文本往返，CSV 导出后再次读取核验。合成测试另验证重叠接管、穿零反转、真实仓位缺口、缺值与零、分页边界和同毫秒饱和；CI 回读发布 CSV，不重跑本地原始归档。
