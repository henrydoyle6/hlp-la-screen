# 每笔接管 HLP 的 FIFO 价差盈亏

计算于2026-11-15。接管索引范围2025-03-22至2026-10-31，使用2026-11-09提取并于2026-11-15逐项复核的真实退出台账；没有新抓取数据。范围内已知接管实际发生于2025-03-26至2026-10-30，最后退出为2026-10-30T02:07:15.937000000Z。

## 主要结果

22,044笔接管、443个接管组，按4个HLP地址和币种分开，共206个组合、1,437个真实仓位周期。FIFO价差盈亏合计 **73,020,695.700172 USDC**。14,436笔归属盈利、7,382笔归属亏损、226笔为零，其中222笔没有新增仓位，另4笔新增仓位退出价差为零。

21,815笔纯开仓或加仓，7笔先平旧仓再反向开仓，合计21,822笔形成新增仓位，全部退出。另222笔只抵消旧仓，没有新批次，归属于新批次的价差盈亏记0，状态明确为“仅抵消旧仓，无新增仓位”。这不代表这些接管没有经济影响：它们触发的旧仓退出盈亏已归回原先接管批次。

现有台账中所有206个组合首笔成交的真实startPosition均为0，故没有未知成本期初旧仓，也没有未平完的新增接管批次。该结论限于索引中已知接管及已核验轨迹；保留原来的4条来源覆盖诊断，不表示全部归档没有任何未观察事件。

## 计算口径与归属

完整读取用户引用的[HLP盈亏计算方法](chatgpt-conversation://6af99f15-f1cc-83ea-9b90-417833be94b3)三轮对话（无更早分页），采用其中说明的FIFO价差方法。引用对话原附件为旧版退出CSV，本次改用已完成原档核验的修复版；价格、官方PnL及原始字段均未改动。

- 多头：配对数量 ×（退出价格 − 接管价格）。空头：配对数量 ×（接管价格 − 退出价格）。一笔分多次退出则求和。
- 同一账户、币种维护队列，不因CSV1接管组变化而清空；按台账已验证的时间、区块及原始事件顺序处理，绝不按tid大小重排。
- 先处理平仓，再处理开仓。反向接管、被清算、ADL、结算均可以是退出，不能只找普通成交。
- 反转接管的平仓部分属于旧批次；开仓部分归新批次及新周期。原始成交仍只有一条，官方PnL不拆分、不重复分配到匹配行。
- `本次触发旧批次FIFO盈亏_勿重复加总`是解释列，已计入旧批次主盈亏。总计只加`FIFO最终价差盈亏_USDC`，不得再加解释列或原始closedPnl。
- 忽略手续费、资金费、未实现盈亏和接管时转入的账户权益；accountValue原样保留在增补CSV1中，但完全不参加本计算。它在多笔接管中可能重复，不能直接当HLP收入加总。
- FIFO是研究者选择的归属规则，不是官方证明的逐批退出标签。结果是按公开成交价计算的已实现持仓价差，不称为HLP完整净收益。
- 使用原档复核确认的规范化仓位和数量，以80位Decimal计算，不通过金额四舍五入修复数量缺口。显示均价为派生除法值；PnL直接由逐对乘积精确相加，不从显示均价反算。

## 官方 PnL 对账：仍有差异

独立买卖现金流、FIFO队列和累计数量区间积分三种计算一致，所有新增数量和退出数量守恒。但不能宣称全部官方PnL对账通过。

|周期分类|周期数|处理|
|---|---:|---|
|FIFO与官方closedPnl合计完全一致|486|保留一致结果|
|非零差额绝对值小于0.01 USDC|138|金额很小，仍标原因未确认，不直接称尾差|
|差额绝对值至少0.01 USDC|792|逐项保留差额及未确认原因|
|官方PnL字段缺失|21|5,239条原始PnL继续留空，不用自行计算值替代|

官方字段完整的1,416个周期：FIFO合计71,579,841.424815 USDC，官方closedPnl合计71,595,682.1878219927 USDC，FIFO减官方为 **−15,840.7630069927 USDC**。因此不能把两者的差异全部归咎于FIFO分配；完整闭合周期在成本及记账口径一致时总价差本应一致。

其余21个缺失官方PnL周期的价格、数量、方向和退出轨迹完整，仍可独立计算FIFO价差，合计 **1,440,854.275357 USDC**。这部分加上1,416个周期的FIFO，才得到73,020,695.700172。

最大已观察对账差额位于PUMP周期`PC1c8176f9f3db976360b1f9a8`：FIFO −298,448.6411200，官方 −294,039.9702600007，差额 −4,408.6708599993 USDC。现有公开成交价与数量足以复算价差，但没有足够证据唯一确定该差额来自官方成本精度、字段记账口径还是其他项目，故没有反算成本或调平。

[官方入场价与PnL说明](https://hyperliquid.gitbook.io/hyperliquid-docs/trading/entry-price-and-pnl)说明加仓更新加权平均入场价、减仓保持入场价，并区分PnL展示与基础记账。该说明本身不能证明历史归档`closedPnl`每一条差额的来源。此前52个周期修复的是**仓位数值表示尾差**，不等同于本次发现的**金额对账差额**。

## 文件与核验

- `takeover_pnl.csv`：主结果，每个接管事件恰好一行，22,044行。包括新增、当场抵消、退出及剩余数量，FIFO价差盈亏，退出时间、原始接管PnL和关联周期对账状态。
- `csv1_with_fifo_pnl.csv`：原CSV1的46列、22,044笔接管及4条诊断逐格保留，右侧追加FIFO结果。原始已有同名列保持原值；规范化计算数量另列。诊断行新增结果为空。
- `fifo_matches_part_*.csv`：386,278条FIFO配对，包含前后成交编号、两端价格、数量、盈亏、退出类型及原台账行号。每条是配对关系，不是新创造的成交；同一退出可以分配给多个开仓批次。官方PnL不重复写入配对表。
- `episode_pnl.csv`：443个组汇总，不改变FIFO队列边界。
- `cycle_reconciliation.csv`：1,437个周期，列出独立现金流、FIFO、官方PnL完整合计或空值、已观察小计、差额和未确认原因。
- `source_diagnostics.csv`：沿用来源覆盖诊断；`validation.json`、`independent_verification.json`为本次真实数据校验结果。

主算法处理387,726条唯一成交；独立算法用累计退出数量区间的价款积分重新计算每个开仓批次，再核验全部配对。全部22,044笔盈亏逐笔一致，开仓/平仓数量逐笔守恒，未发现跨账户、跨币种、跨错误周期或用未来开仓匹配过去退出。CSV1原46列逐格保持不变。8项合成边界测试覆盖重叠、未知旧仓、反转、纯抵消、普通开仓/ADL、缺口、精度和地址隔离；真实全量证据与CI合成测试分开保存。
