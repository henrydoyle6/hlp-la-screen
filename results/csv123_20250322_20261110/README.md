## 数据与验证

独立扫描本地 2026-11-01—11-10 共 240 个官方 fills-by-block 对象，完整压缩文件 SHA256 均与下载回执一致。接管集合还与另一份独立本地扫描的 271 笔结果逐 ID 核对一致。沿用四个既有 HLP 接收地址及原 backstop 判定、同币种同方向相邻间隔不超过 30 分钟的分组规则。两个历史格式交接空窗继续忽略，实际 fills 缺口只分段，两侧已知 episode 保留。

新增 9 组从 0xArchive 获取完整 L4 检查点和有序 diff。锁定 Tn 前最近的实际完整检查点 S，使用本地官方 fills 的真实区块时间绑定 S/B/A，回放 `(S,B]` 的全部变动，再继续回放到后置检查点 A。整个目标块 B 均应用完毕后取单侧簿。引擎与独立字典、后置检查点、API 实际币种前沿的逐单 ID/方向/价格/剩余数量比较均严格为零差异。历史 WIF 原生对照用于适配器校准，本次复用其证据，未重新下载原生 ABCI。

0xArchive 检查点与 diff 的一致性不等于为每个币种独立证明每个链区块无事件；这项来源边界继续保留。取样字段明确为 `block_end`，新增 L4 行的 `snapshot_lag_ms` 留空。前 354 组继续保留原历史 L2 方法，不能把整段结果称为完整 L4。

所有成功 CSV3 均由独立 Decimal 程序重新核算。LA 只覆盖实际模拟成交数量，未成交部分不填收益。早期 L2 的档内数量不乘订单数 `n`，部分成交的多订单价位仍无法推断精确成交订单笔数。生产分组、回放、LA 和 31 个保护片段没有修改。
